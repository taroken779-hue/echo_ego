# Echo Ego

日本語の短文を入力して、Irodori-TTSの声で話すWindowsローカルアプリ。自分の声の録音・登録、発話キュー、生成済み定型句、読み辞書、履歴保存に対応します。

OmniVoiceによる日本語・英語発話、日本語入力からのローカル日英翻訳、読み辞書のプレビューにも対応します。追加導入は`setup_omnivoice.bat`。声の管理で3〜10秒の参照区間と正確な文字起こしを保存して準備し、発話画面でエンジンを選択してください。[操作ガイド](docs/OMNIVOICE_GUIDE.md) / [実装・検証結果](docs/OMNIVOICE_IMPLEMENTATION.md)。日本語の初期標準はIrodoriを維持します。

## 導入・起動

1. Git for Windowsとuvをインストールします。
2. `setup.bat` で専用Python環境・公式Irodoriソース・モデルを取得します。
3. `start.bat` を実行し、ブラウザーで `http://127.0.0.1:8100/` を開きます。「準備完了」後に文を入力してEnterで発話します。
4. 終了は `stop.bat` または設定画面の「アプリを終了」。タブを閉じるだけではGPU常駐は終了しません。

標準はNVIDIA CUDA GPU・MF 4ステップ・BF16です。CPUは `scripts/setup.ps1 -Cpu` で導入できますが、会話の応答性能は未検証です。モデル本体は約3.1GBで、初回は他の依存も取得します。

## 機能

- Enterで発話、Shift＋Enterで改行、Escで全停止。IME変換確定中は送信しません。
- 再生中にも次の文を生成する発話キュー。待ち文の取消と停止後の古い結果の破棄。
- 声の試聴・名前変更・お気に入り・削除。マイク録音またはWAV登録。プリセット4種類はこのPC内で生成します。
- 編集・並べ替え可能な定型句とAlt＋1〜9。事前生成した音声を再利用し、設定変更時は別キャッシュにします。
- 読み辞書、再生音量、対応ブラウザーでの出力先選択。
- 生成日時付き履歴とWAV保存、個別・全件削除、直前の削除の取り消し。
- 履歴保存は初期オフ。オンならPC内に音声込みで保存し、件数・日数・容量で制限します。
- アプリ内でIrodoriのパス・GPU/CPU・起動時読み込み・オフライン設定を確認・変更できます。

## 保存とプライバシー

`config.local.json` はPCごとの環境設定、`data/` は設定・履歴・定型句・声の特徴、`voices/` は登録WAV、`runtime/` はモデルと推論コード、`.runtime/` はログです。Gitの追跡と配布ZIPから除外します。初回導入後の通常発話はローカル推論です。参照音声の利用許可を確認してください。

## 応答時間

「送信から再生開始まで」は待ち行列を含め、ブラウザーへ再生をスケジュールするまでの時間です。物理スピーカーから音が出た瞬間の測定ではありません。先頭無音と出力機器の遅延は別途加わります。起動直後・初めての声・文の長さで時間は変わります。

開発PCのRTX 5080・16GBで実GPU合成を検証しています。以前の試作品の短い挨拶はブラウザーで約0.43〜0.91秒と変動しました。個々の測定は性能保証ではありません。今回の検証と未検証範囲は実装・検証記録に記載します。

## 開発と配布

`python -m unittest discover -s tests -v` で保存処理と設定検証を確認できます。JavaScriptは `node --check static/app.js` と `node --check static/features.js`。`python scripts/package_release.py` で個人データを含まない `dist/echo-ego-source.zip` を作ります。GitHub公開は別操作です。
