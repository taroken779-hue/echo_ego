# OmniVoice参照設定の自動入力（2026-10-21）

## 変更

- 標準4種類は生成時の共通文章と全区間を初期値にする。音声全体が3〜10秒の場合のみ適用し、既存の保存設定を優先する。未生成の声は参照欄を開いた際に作成する。
- 追加プリセットとユーザー録音を含む各声に「区間と文字を自動入力」「この区間を文字起こし」「選択区間だけ試聴」を追加。
- 自動選択は音量と無音から3〜10秒の候補を選ぶ。長い音声は7秒付近の無音を優先する。短い録音や無音はエラーとして案内する。
- Whisper large-v3-turboをOmniVoice専用環境でCPU実行する。元WAVの指定区間だけを16kHzへ変換して認識する。文字起こしモデルを処理後に解放し、TTSとの実行を直列化する。録音を外部へ送信しない。
- 自動認識は未保存の下書き。確認・修正後に利用者が保存する。保存時と利用時に録音のSHA-256を確認し、変更された録音と古い文字を組み合わせない。
- 通常発話には保存した参照を再利用する。導入スクリプトはモデルrevisionをローカルmanifestへ保存し、再導入時にも維持する。既存Irodori環境の変更は不要。

## API

`POST /api/v2/voices/{id}/auto-reference` に `reference_language`（ja/en）を渡す。`clip_start_ms` と `clip_end_ms` は両方を指定すると区間を固定し、両方省略すると自動選択する。202で受け付け、同URLのGETで `transcribing / ready / failed` を照会する。`ready.reference` は音声ハッシュ付きの下書きであり、参照の保存APIへ渡して確定する。別の文字起こし中は429、同じ声の異なる要求が処理中なら409。

`POST /api/v2/voices/{id}/standard-reference` は標準の元音声を用意し、既存設定または標準の初期値を返す。参照GETの `reference_audio_changed` がtrueなら再作成が必要。

- 実HTTP経路：ナレーター音声の区間自動選択・文字起こしが成功。0〜3.8秒へ区間を指定した文字起こしも成功し、保存済み設定が不変であることを確認。
- 標準4種類の参照音声長：男性・落ち着いた声5.76秒、女性・落ち着いた声6.00秒、男性・明るい声5.64秒、女性・明るい声6.04秒。全て初期値の適用条件内。
- 標準男性声のOmniVoice準備が完了し、日本語3.00秒・日本語から翻訳した英語2.16秒の非ゼロWAVを取得。検証発話は試聴モードとし、履歴へ追加しない。
- ブラウザー：自動入力中の入力無効化、下書きの反映、選択区間の試聴開始・Escによる停止を確認。

人による聴取での音質・本人らしさ・全ての声や言語での認識精度は未検証。自動選択は意味上の文末を保証しない。標準の既知文章も生成音声に読み誤りがある場合は手動修正または再文字起こしで調整する。
