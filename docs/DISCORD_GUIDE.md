# Discord・VB-CABLEの使い方
入力した文章を読み上げ、Discordの通話相手へ届ける手順です。最初はヘッドホンを接続し、通話に入る前にマイクテストで確認してください。Irodori-TTSでもOmniVoiceでも、音声を渡す手順は同じです。
### 1．音声の流れを知る
Echo Ego → 仮想ケーブルの再生側 → 仮想ケーブルの録音側 → Discordのマイク → 通話相手、の順に音が流れます。「出力」は音を送る先、「入力」は音を受け取る元です。
Windowsでは、Echo Egoの出力先は「CABLE Input (VB-Audio Virtual Cable)」、Discordの入力先は「CABLE Output (VB-Audio Virtual Cable)」です。ケーブルの入口に送り、出口から受け取るため、この組み合わせになります。Macでは「VB-Cable」など同じ名前が入出力の両方に表示される場合があります。名前だけでなく、出力側・入力側のどちらを選んでいるかも確認してください。
Discordの出力先は、自分が相手の声を聞くヘッドホンです。ここを仮想ケーブルにすると、相手の声が通話へ戻る原因になります。
### 2．VB-Audio Virtual Cableを用意する
[VB-AUDIO公式のダウンロードページ](https://vb-audio.com/Cable/)から、使うOSのVB-CABLEを入手します。このアプリには仮想ケーブルの自動インストール機能はありません。
- Windows：ZIPを展開し、公式のセットアップを管理者として実行してインストールします。終了後はPCを再起動してください。
- Mac：Mac用パッケージを開き、インストーラーの案内に従います。再起動を求められた場合は再起動し、音声デバイス一覧に仮想ケーブルが現れることを確認します。
このプロジェクトの起動手順はWindows向けです。以下のMacの説明は、Macで発話音声を再生できる環境を用意した場合の音声接続手順で、Mac上でのモデル起動を保証するものではありません。
### 3．Echo Egoの出力先を選ぶ（Windows・Mac共通）
- 手順1：Echo Egoの「設定」を開き、「再生と履歴」の「出力先を確認」を押します。ブラウザーに機器の利用許可が出た場合は、内容を確認して許可します。
- 手順2：「音声出力」で、VB-Audio Virtual Cableの再生側を選びます。Windowsなら「CABLE Input」、Macなら出力一覧の「VB-Cable」などです。「標準の出力先」のままにしないでください。
- 手順3：「設定を保存」を押します。「確認音を鳴らす」は選んだケーブルへ音を送ります。ヘッドホンから直接聞こえなくても、必ずしも故障ではありません。後のDiscordマイクテストで確認します。
- 手順4：「発話」へ戻り、お気に入りの声を選びます。OmniVoiceでは、その声の参照区間と、区間に一致する文字起こしを先に保存してください。まず短い文で試します。
出力先が選べないブラウザーでは、以下のOS側の方法を使います。出力先が消失するとEcho Egoは標準出力へ戻るため、ヘッドホンの抜き差しや再起動後には選択を確認してください。
### 4．Windowsの音声入力・出力を設定する
- 手順1：Windowsの「設定 → システム → サウンド」を開きます。通常の「出力」はヘッドホン、「入力」は普段の実物のマイクのままで構いません。Echo EgoとDiscordで個別に指定すれば、Windows全体の既定値を仮想ケーブルへ変える必要はありません。
- 手順2：サウンドの出力一覧に「CABLE Input」、入力一覧に「CABLE Output」があることを確認します。ケーブルが無効・ミュートになっている場合は解除します。入力の「CABLE Output」を一時的に選び、Echo Egoで発話したときに入力メーターが動くかを確認することもできます。確認後は普段のマイクへ戻します。
- 手順3：Echo Ego内で出力先を選べない場合は、「サウンド → 音量ミキサー」で、音声を再生しているブラウザーの「出力デバイス」を「CABLE Input」にします。アプリ一覧に出ない場合は、一度Echo Egoで確認音を鳴らしてから開き直します。
ブラウザー単位の変更では、同じブラウザーの動画などもケーブルへ流れる場合があります。通話用のブラウザーを分けるなどして、別の音を再生しないでください。Discordの出力は引き続きヘッドホンを選びます。
### 5．Macの音声入力・出力を設定する
- 手順1：Appleメニューの「システム設定 → サウンド」を開きます。「出力」はヘッドホン、「入力」は普段の実物のマイクにします。Echo Egoでケーブルを個別指定できる場合、Mac全体の出力先は変更不要です。
- 手順2：「出力」と「入力」の各一覧に、VB-CABLEに対応する機器があることを確認します。同じ「VB-Cable」という名前でも、出力側はEcho Egoから送る先、入力側はDiscordが受け取る元です。
- 手順3：Echo Ego内で出力先を選べない場合は、Macの「サウンド → 出力」を仮想ケーブルにし、Echo Egoを「標準の出力先」にして保存します。これはMac全体の再生音を送る方法です。通知や他のアプリの音も通話へ入る可能性があるため、不要な再生を止めてください。Discordでは出力先を明示的にヘッドホンにします。
- 手順4：Discordが入力を利用できないときは、「システム設定 → プライバシーとセキュリティ → マイク」でDiscordの許可を確認します。ブラウザー版Discordなら、そのブラウザーのOS側の許可とDiscordサイト側のマイク許可も確認します。
Mac全体の出力先を変更した場合、通話終了後に「サウンド → 出力」をヘッドホンへ戻してください。
### 6．Discordのマイクを設定する（Windows・Mac共通）
- 手順1：Discordの画面左下にある歯車の「ユーザー設定」を開き、「音声・ビデオ」を選びます。表示名や配置はバージョンによって異なります。
- 手順2：「入力デバイス」で仮想ケーブルの録音側を選びます。Windowsは「CABLE Output」、Macは入力機器一覧の「VB-Cable」などを選びます。「Default／既定」ではなく機器名を指定します。
- 手順3：「出力デバイス」で自分のヘッドホンを選びます。仮想ケーブルは選びません。「入力音量」とEcho Egoの音量を、ミュートではない適度な大きさにします。
- 手順4：「入力モード」は、まず「音声検出／音声アクティビティ」にします。「プッシュ・トゥ・トーク」を使う場合は、生成待ちではなく音声が再生されている間、Discordの送信キーを押し続ける必要があります。
- 手順5：「マイクテスト」の「確認しましょう／Let's Check」を開始し、Echo Egoへ戻って「こんにちは。音声のテストです。」と入力して発話します。Discordからヘッドホンへ折り返された音声が聞こえるか確認します。終わったらマイクテストを停止します。
- 手順6：ボイスチャンネルへ入り、Discordのマイクのミュートを解除します。相手に音量、言葉の先頭、途切れがないかを確認してもらいます。
### 7．音が届かない・途切れるとき
- 音がまったく届かない：Echo Egoの出力がケーブルの再生側、Discordの入力が同じケーブルの録音側になっているかを確認します。WindowsではInputとOutputを逆にしないでください。インストール直後ならPC・ブラウザー・Discordの再起動も確認します。
- 入力メーターは動くのに相手に届かない：Discordのミュート、入力モード、送信キー、チャンネルでの発言権限を確認します。
- 小さい音や文頭が消える：Discordの入力感度を調整し、必要に応じてノイズ抑制・エコー除去・自動ゲイン調整を一つずつ変更して、同じ短文で比較します。まずはヘッドホンで試してください。
- 自分には聞こえないが相手には聞こえる：ケーブルへの送信だけなら正常です。現在のEcho Egoにはケーブルとヘッドホンへ同時出力する専用機能はありません。最初はDiscordのマイクテストで確認します。
- 自分の肉声も一緒に送りたい：この手順は合成音声だけを送ります。肉声へ戻すときはDiscordの入力を実物のマイクへ変更します。両方を同時に送るには別途音声ミキサーが必要です。
### 終了後と参考情報
通話を終えたら、必要に応じてEcho Egoの出力をヘッドホンに変更して保存し、Discordの入力を普段のマイクへ戻します。変更したWindowsの音量ミキサーやMac全体の出力先も元へ戻します。
生成まではこのPC内の処理ですが、Discordへ送った音声はDiscordを通じて通話相手へ届きます。
参考：[VB-CABLE公式](https://vb-audio.com/Cable/)、[Windowsのサウンド設定](https://support.microsoft.com/en-US/Windows/Hardware/Audio/fix-sound-or-audio-problems-in-windows)、[Macの入力設定](https://support.apple.com/guide/mac-help/change-the-sound-input-settings-mchlp2567/mac)、[Macの出力設定](https://support.apple.com/guide/mac-help/change-the-sound-output-settings-mchlp2256/mac)、[Discordのマイクテスト](https://support.discord.com/hc/ja/articles/360020641332/マイクテスト)。実際のDiscord通話とMac実機での接続は別途確認してください。
