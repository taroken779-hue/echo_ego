# Echo Ego：Taroken工房を参考にしたテーマ

更新日：2026-10-04

参考：[Taroken工房](https://tarokenkoubou.com/)。実際の画面と公開CSSの配色を確認して、濃い茶色・真鍮・銅・生成りの組み合わせをEcho Egoへ反映した。

| 用途 | 色 |
| --- | --- |
| 背景 | `#140e0a` |
| パネル | `#1f150f`〜`#261a12` |
| 主な文字 | `#f4ebd0` |
| 補助文字 | `#bfa883` |
| 真鍮のアクセント | `#c59b27` |
| 銅のアクセント | `#b87333` |

見出しはWindowsの游明朝などのローカル明朝体、操作と入力は游ゴシック等で読みやすさを維持する。英字の小見出し、真鍮の細い枠、銅色のグラデーションボタン、四隅の小さな鋲、薄い歯車の背景で雰囲気を合わせる。ソフト名は小さいまま表示する。

アイコンは独自のSVG。ブランドは歯車と音声、操作は発話・履歴・停止・登録・再生・保存・削除・取り消し・設定・ローカル処理のマークを作成した。空の履歴にはレコード盤のモチーフを使用する。

SVG・背景・フォントはローカルで利用するため、画面表示に外部のフォント配信や画像配信を必要としない。参考サイトの写真やロゴ画像は利用していない。

実装：`static/style.css`、`static/index.html`、`static/icons.svg`、`static/gear-watermark.svg`、履歴内アイコンは `static/app.js`。
