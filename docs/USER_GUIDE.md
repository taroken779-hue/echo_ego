# Echo Ego 使い方
## はじめに
start.batをダブルクリックすると、このPCのブラウザーでEcho Egoが開きます。モデルの読み込みと初回生成が終わり「準備完了」になったら発話できます。使い終わったら「設定 → Irodori-TTSの環境設定 → アプリを終了」またはstop.batで終了します。タブを閉じるだけではモデルはGPUに常駐します。
## 発話する
文を入力してEnter、または「発話する」を押します。Shift＋Enterは改行です。日本語入力の変換確定中のEnterでは送信しません。1文は160文字まで。声・速さ・生成ステップは自動保存されます。発話文章の入力途中の内容はディスクに保存しません。
- 生成中・再生中にも次の文を送れます。待ち行列は最大8件です。次の文の生成は前の音声の再生中に進みます。GPUでの生成は1件ずつです。
- 待っている文は個別に「取消」。生成中も含めて止めるときは「停止」またはEsc。GPU計算そのものの強制中断はせず、結果を破棄して再生を止めます。
- 「送信から再生開始まで」は待ち行列の待ち時間も含みます。ブラウザーが再生を始める時点までの計測で、音声先頭の無音とスピーカーの遅延は別です。
## 声の管理
「声」画面で名前変更・お気に入り・参照音声の試聴・使用する声の選択ができます。名前変更で声の内部IDは変わりません。追加した声だけ削除できます。削除時は登録WAVと前処理キャッシュを消します。すでに生成した発話履歴は別途削除してください。
プリセット4種類は、Irodoriの声の説明による生成機能でこのPC内に作成します。初めて使う声は参照音声の作成に追加時間がかかります。最初に「試聴」を押した場合も音声を生成して確認できます。生成済みの参照音声は次回以降も使います。モデルの乱数・環境によって声には差が生じます。既存の許可されたWAVを追加する場合は、環境設定のプリセットフォルダーに置いてください。
## 自分の声を録音・登録
「声」画面でマイクを確認し、録音開始・録音終了を押します。マイクの利用許可はブラウザーで求められます。最大30秒で自動停止し、音量メーターと試聴で確認してから「この録音を登録」を押します。「取消」は保存せず終了します。外部の録音を使う場合は発話画面から1〜30秒・20MB以内のWAVを登録します。
静かな部屋で、自然に数文話してください。本人の声、または明確に利用許可を得た声を使ってください。録音・参照音声・声の特徴キャッシュはPC内に保存します。
## 定型句と読み辞書
「設定」で最大9件の定型句を編集し、↑↓で並べ替えて保存します。発話画面のボタン、またはAlt＋1〜9で送信できます。このショートカットはEcho Egoのタブ内だけで動きます。他のアプリを操作するグローバルキーではありません。
「定型句を事前生成」で音声を準備すると、次回は生成処理を省略できます。声・速さ・ステップ・モデル・読みの変更はキャッシュの識別に含まれます。準備中に発話を送ると、現在の準備1件が終わるまで発話が待つ場合があります。「準備を停止」は次の準備を止めます。定型句キャッシュは最大64件・50MBで古いものから整理します。
読み辞書は「単語」「読み」を登録します。長い単語を優先し、一度だけ置換します。表示する入力文・履歴には元の文章が残ります。辞書を変更すると定型句キャッシュを削除します。
## 履歴の保存・削除
標準ではディスクへの履歴保存はオフです。タブ内に最大10件保持し、再読み込みで消えます。「設定」で保存をオンにすると、それ以降の発話は音声込みでPC内に保存し、再起動後も一覧から再生できます。オンにする前の履歴は自動でディスクへ移しません。
- 保存上限は件数・日数・MBを設定できます。保存時と履歴表示時に上限を超えた古い音声を整理します。
- 履歴には生成完了日時を日本時間・秒単位で表示します。再生しても元の生成日時を変えません。定型句のキャッシュを使った場合は元の音声の生成日時です。
- 個別削除・全件削除・直前の削除の取り消しができます。取り消し用の音声はこのタブ内に保持します。次の削除かタブ終了で保持を終えます。
- 保存をオフにして設定を保存すると、ディスク上の全履歴を削除します。そのタブですでに表示していた履歴は再読み込みまで残る場合があります。
SQLiteの削除は論理的な削除とsecure_deleteを使います。バックアップ・OS・SSD上の完全消去は保証しません。個人の録音をGitHubや配布ZIPに含めないでください。
## 音量・出力先・通話への接続
設定で音量と出力先を選び、確認音で試します。ブラウザーが出力先選択に対応しない場合はWindowsのサウンド設定を使います。ヘッドホンなどを抜いた場合は標準出力に戻ります。
通話に送る場合は、導入済みの仮想オーディオ機器をEcho Egoの出力先、通話アプリの入力先に選びます。仮想オーディオ機器のインストールはこのアプリでは行いません。スピーカー音がマイクに回り込まないようにしてください。通話アプリ側で実際の受信音を確認してください。
## トラブル時
「使い方 → Irodori-TTSの設定」に導入・エラー対処を記載しています。設定画面にGPU・VRAM・モデル有無・保存先を表示します。ログは.runtime/server-error.logです。通常の合成ログには入力した文章が記録される場合があります。共有前に文章・ユーザー名・個人パスを除いてください。
