# OmniVoice・英語モード・読み辞書

## 導入

このPCにはOmniVoice・日英翻訳・文字起こしモデルを専用環境へ導入済み。別PCでは`setup.bat`でアプリと標準のOmniVoice・補助モデルを導入する。以前に導入済みでも、自動文字起こしモデルがない場合は再実行する。モデル取得時だけネットワークが必要。導入後の発話・翻訳・文字起こしはローカルで処理する。

OmniVoice公式ソースは固定コミット、Python依存は`requirements-omnivoice.lock.txt`、モデルとCodecと翻訳器は`runtime/omnivoice/manifest.json`のrevisionを使用する。再実行では既存のモデルrevisionを維持する。アプリ用環境とモデル用環境は分離する。

## 声の準備

1. 「声」を開き、使う声の「選択モデルの声を準備」を開く。
2. 標準4種類の声は、元音声全体が3〜10秒なら既知の生成文章と全区間が入力済み。未生成の声は、この欄を開くと元音声を作成する。保存済みの手動設定を優先する。
3. その他の声は録音の言語を選び、「区間と文字を自動入力」を押す。3〜10秒の区間候補と、その区間だけの文字起こしが入力される。「選択区間だけ試聴」で確認し、誤認識は修正して「参照を保存して準備」を押す。
4. 準備完了後、発話画面でその声を選ぶ。音声モデルは設定画面で選ぶ。

最初のモデル読込・声の特徴抽出・ウォームアップには時間がかかる。自動入力は下書きであり、保存するまで既存設定を変更しない。元録音も上書きしない。文字起こしはCPUで動作し、処理後にモデルを解放する。通常の発話ごとには文字起こししない。

区間を変更した場合は「この区間を文字起こし」で、その区間に合わせて再入力できる。自動選択は無音を区切りの候補にするが、文の終わりや認識の正確さは保証しないため、区間と文字を確認する。保存した参照は再利用され、録音の内容が変わると作り直しが必要になる。

3秒より短い録音は保持するが、OmniVoiceで利用するには長い録音を登録する。録音が10秒を超える場合、選んだ区間の文字起こしだけを入力する。日本語参照で英語を話すと日本語由来のアクセントが残ることがある。

## 日本語と英語

「日本語」「英語に翻訳」の両方で設定画面の選択モデルを使う。現在はOmniVoice。対象言語に未対応のモデルでは発話できない。日本語原文を入力してEnterで送信すると、英文を表示して英語音声を再生する。

OmniVoiceの生成ステップは詳細欄の32（標準）/16（速度比較）から選ぶ。表示する生成設定はモデルの能力情報で決まる。Irodoriは廃止済み。

別エンジンへ変える際は、GPU常駐モデルを入れ替えるため準備時間が加わる。日英ともOmniVoiceならTTS自体の入替えは不要。初回の声準備を済ませてから会話に使うと待ち時間を抑えられる。

Enterで発話、Shift+Enterで改行、Escで全停止。停止は即座にブラウザー再生を止め、遅れて返った音声を破棄する。実行中のGPU推論自体は完了またはタイムアウトを待つことがある。待ち文は個別に取り消せる。

## 読み辞書

「設定」の「読み辞書」で単語・かなの読み・有効/無効・適用範囲・メモを設定する。最大100件。

例: 単語「日本橋」、読み「にほんばし」。原文「日本橋で集合します。」を表示したまま、TTSへは「にほんばしで集合します。」を渡す。

- 長い単語を優先し、置換後の読みをさらに置換しない。
- 「文中の一致」は出現箇所を置換。「文全体の一致」は句点も含めて入力全体が一致する場合だけ適用。
- 「未保存の読みを確認」で適用結果と項目を表示。「未保存の読みを試聴」は保存せずに合成し、履歴や定型句音声へ保存しない。
- 「設定を保存」で辞書を確定。辞書更新後の定型句は再度「事前生成」する。
- 英語モードの翻訳には日本語原文を渡すため、かな読みを翻訳へ混ぜない。
- 送信済み文は受付時の辞書を使う。保存済み履歴の再生も当時の音声を使う。

新しい読みはひらがな・カタカナで入力する。ピッチアクセントを指定する辞書ではなく、正しいかなでも発音品質は試聴が必要。旧辞書は移行して保持する。複数タブで編集が競合したら保存せず表示するため、未保存内容を控えて再読み込みする。

## 保存と利用条件

自由入力と音声は、履歴保存オフならタブとサーバーの一時メモリーに保持する。再読込または保持期限で消える。定型句の事前生成と、登録した参照音声/文字起こし/声特徴は別途PC内に保存する。

OmniVoiceのコードはApache-2.0、公開重みはCC-BY-NCと提供元が明記している。商用利用・再配布の判断は別途必要。モデル、録音、特徴、文字起こし、DB、ログ、ローカル設定はソースZIPへ含めない。

英語翻訳は小型のOPUS-MTをCPUで実行する。省略の多い会話、固有名詞、否定、数値には誤訳の可能性があり、表示された英文も確認する。翻訳失敗時に原文を英語として無理に読み上げない。
