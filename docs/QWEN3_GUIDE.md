# Qwen3-TTS（低遅延）

音声全体の完成前から再生する、新規導入の標準モデルです。OmniVoiceは任意で追加できます。Qwen3-TTS 0.6B Baseに、第三者実装faster-qwen3-ttsのCUDA Graphs・逐次生成を組み合わせています。

## 導入と切り替え

1. uvを用意し、Echo Egoのフォルダーでsetup.batまたはsetup_qwen3.batを実行します。どちらか1つで、アプリ・独立した翻訳／文字起こし環境・Qwen3を導入します。OmniVoice本体・音声Codecは取得しません。
2. 既存環境を更新する場合は先にstop.batで停止してから同じセットアップを実行します。初回は専用Python 3.11環境・CUDA版PyTorch・固定した依存パッケージ・0.6B Baseモデルを取得します。ネット接続と空き容量が必要です。NVIDIA CUDAとbfloat16に対応するGPU・ドライバーが必要で、CPU実行には対応しません。
3. セットアップ完了後、start.batで起動します。「設定 → 音声モデル・実行環境」を開き、「Qwen3-TTS（低遅延）」を選択します。選択は自動保存されます。「環境設定を保存」を押す必要はありません。
4. 「声」で使用する声の「選択モデルの声を準備」を開きます。声を含む3〜10秒の参照区間と文字起こしを確認し、「参照を保存して準備」を押します。自動入力は下書きなので、選択区間を試聴して内容を修正してください。
5. 「発話」で声を選び、準備完了を待って短い文を送ります。初回・モデル切り替え直後はモデル読込とCUDA Graphsの準備に時間がかかります。起動直後の待ち時間と、準備済みの状態での発話時間を分けて確認してください。

起動・終了はこれまでと同じstart.bat / stop.batを使用します。追加セットアップは選択済みモデルを変更しません。OmniVoiceへの切り替えも同じ設定欄です。GPU上のモデルは切り替え時に入れ替わり、待ち行列と再生は停止します。モデルを切り替えたら定型句も必要に応じて事前生成してください。

日英翻訳と自動文字起こしは独立したruntime/auxiliary環境で行います。Qwen3だけの新規導入ではOmniVoice環境は不要です。参照音声は自分の録音または利用許可のあるWAVを使います。既存環境の手動パスと選択モデルは保持し、旧環境は自動削除しません。

## 声と生成設定

- 参照音声は3〜10秒の区間と、その区間に一致する文字起こしを設定します。既存のWAVも条件が合えば使用できます。長い録音は「声」画面で区間を指定します。
- 日本語・英語に対応します。英語に翻訳する場合は、翻訳処理の時間が追加されます。
- 詳細欄のチャンクサイズは4または8です。標準は4。音声を小分けに受信し、AudioWorkletで順番に再生します。
- 話す速さの変更と声のデザインは、このアダプターでは非対応です。速度欄は無効になります。
- 標準声はOmniVoiceで作成済みの元音声を参照として使えます。未作成の場合はOmniVoiceを任意追加して選び、「声」で試聴または参照設定を開いて元音声を作成してからQwen3へ戻します。Qwen3を選んだままでは標準声を新規作成できません。自分のWAVを登録して使うこともできます。
- 停止・Escは受信と再生を中断します。途中までの音声を履歴や定型句キャッシュへ保存しません。生成処理の停止反映を待つため、直後の次の発話が遅れることがあります。
- 完成した発話は通常どおり履歴から再生・WAV保存できます。生成済み定型句は完成WAVを再利用します。

## 性能と制約

今回の統合検証では最初のPCM受信が約0.37秒、ブラウザー表示の再生開始が約0.49秒でした。文章・GPU・声・待ち行列で変わる単発値で、物理的な出音の測定ではありません。生成音声の先頭無音も加わります。

評価では一部の文で語の重複がありました。短文から試し、用途に合う音質・発音・声の類似性を確認してください。人による聴取評価やDiscord通話の実機確認は未実施です。1発話30秒以内、生成トークン数に上限を設けています。

## 実装とトラブル対応

モデルIDは `qwen3`、バックエンドは `qwen3_fast` です。アプリ・OmniVoiceと別の `runtime/qwen3-fast/.venv` を使い、モデルは `runtime/qwen3-tts/model-0.6b` に保存します。

検証済み組み合わせはfaster-qwen3-tts 0.5.4、qwen-tts-hf 0.1.1.post1、transformers 5.15.1、PyTorch 2.10.0+cu128です。公式のqwen-ttsとqwen-tts-hfを同じ環境へ混在させないでください。依存バージョンを固定しているため、更新は再検証が必要です。

準備に失敗する場合は参照区間・文字起こしを確認し、アプリを停止してセットアップを再実行します。GPUメモリ不足の場合は他のGPUアプリを終了してください。初回取得後の発話はローカルで処理します。

- アプリ・補助環境がない：通常のsetup.batまたはsetup_qwen3.batを完了します。開発者向けの個別スクリプトはコンポーネント単位の処理です。
- GPU確認で失敗：対応ドライバー・CUDA利用可否・bfloat16対応を確認します。CPUで使う場合はOmniVoiceを選びます。
- モデル選択欄に出ない：セットアップの登録完了を確認し、stop.bat / start.batでアプリを起動し直します。
- 既存のqwen3設定が異なるというエラー：手動設定を保護するため登録を停止しています。config.local.jsonのmodels.qwen3と上記の専用環境・モデルパスを比較してください。
- 声が使えない：選択モデルの参照設定、3〜10秒の区間、文字起こしの一致を確認します。OmniVoiceで使えてもQwen3用の確認・保存が必要な場合があります。
- 自分には聞こえないがDiscordには届く：出力先が仮想ケーブルなら起こり得ます。使い方の「Discord・VB-CABLE」に自分の発話を聞く手順があります。
